S1物質の性質 / 問1付近

鉛・カドミウムの性質と発生源

PbS・鉛フューム・CdSを区別

重要ポイントを確認
  • 鉛の代表鉱石は方鉛鉱（PbS）。製錬時の酸化鉛を含むダストに注目。
  • カドミウムは亜鉛鉱に随伴しやすく、硫化物CdSは黄色で顔料などに使われる。
  • 金属CdとCdO・CdSでは色、用途、発生過程が異なる。

金属と化合物を混ぜず、鉱石→工程→物質の順に覚える。

S2物質の性質 / 問2付近

ふっ素・塩素・HF・HCl

色・水との反応・腐食性で分類

重要ポイントを確認
  • F₂は淡黄色、Cl₂は黄緑色の気体。HFとHClは無色。
  • HFの水溶液は弱酸でも、皮膚・ガラスなどに対して危険な腐食性を示す。
  • Cl₂は水と反応し、HClとHClOを生じる（平衡反応）。

「酸の強弱」と「実際の危険性」は別の性質。

S3ガス吸収 / 問3〜4付近

ガス吸収と吸収装置

境膜抵抗・塔の形式・圧損

重要ポイントを確認
  • 水に溶けやすいガスは、一般にガス側の物質移動抵抗が重要になりやすい。
  • 充填塔は大きな接触面積、スプレー塔は構造が簡単で低圧損、ベンチュリは高い接触強度と高圧損。
  • ぬれ壁塔は伝熱・冷却を考えた吸収に有用。充填塔ではローディングとフラッディングにも注意。

抵抗の支配関係は液組成・操作条件にも依存する。試験の典型条件で整理する。

S4ガス吸着 / 問5付近

ガス吸着と活性炭

単分子層・破過・添着炭

重要ポイントを確認
  • ラングミュアー式は単分子層吸着、BET式は多分子層吸着モデル。
  • 活性炭は一般に多くの非極性有機物を吸着しやすい。対象によって添着処理を行う。
  • 破過は出口濃度が管理基準に達すること。入口濃度に等しくなることではない。

元記事では吸着分野が10年間のうち9年度で登場。破過の定義を落とさない。

S5安全対策 / 問6〜7付近

特定物質と事故時の措置

毒性・水反応・着火性を判断

重要ポイントを確認
  • 漏えい源の探索で有害ガスを直接嗅がない。必要な検知と立入管理を優先する。
  • 空気より重い蒸気は低所滞留に注意。可燃性物質では着火源を管理する。
  • 水と危険な反応をする物質に安易に散水しない。クロルスルホン酸は代表例。

これは試験学習用の原則。実際の事故対応はSDS・緊急時手順・専門担当者に従う。

S6JIS分析 / 問8付近

ふっ素化合物の排ガス分析

NaOH・NaF・妨害イオン

重要ポイントを確認
  • 代表的な排ガスふっ素分析ではNaOH溶液で吸収し、ふっ化物イオンとして分析する。
  • 標準液の調製にNaFが使われる。Al³⁺やFe³⁺による妨害に注意する。
  • イオン電極法ではイオン強度調整用緩衝液を用いる。必要に応じて蒸留などの分離操作を行う。

吸収液や前処理の条件は採用するJISの版と分析方法で確認する。

S7JIS分析 / 問9付近

塩素・塩化水素の排ガス分析

Cl₂とHClを混同しない

重要ポイントを確認
  • 塩素には吸光光度法とイオンクロマトグラフ法などがある。IC法でシアン酸イオンを測る手順を理解する。
  • HClではIC法、イオン電極法、硝酸銀滴定法などを区別する。
  • 原記事ではHClの代表的な吸収液を「IC＝水／滴定＝NaOH／イオン電極＝KNO₃」と整理。

試薬の使い分けは規格版・測定法で異なるため、本文の操作条件を確認する。

S8JIS分析 / 問10付近

鉛・カドミウムの機器分析

ICP-MS・AAS・Pd・Y

重要ポイントを確認
  • フレーム原子吸光、電気加熱原子吸光、ICP発光、ICP質量分析の原理を区別する。
  • 電気加熱AASではPd系のマトリックスモディファイヤーが利用される例がある。
  • ICP-MSはイオンの質量電荷比（m/z）で分離し、Y（イットリウム）などの内標準を使う方法がある。

装置間の定量下限は測定元素・試料・方法条件によって変わる。絶対的な順位と断定しない。

該当するテーマがありません。

03 / SECOND PRIORITY

得点を安定させる Aランク。

Sランクの骨格を覚えたら、装置の特徴や物質ごとの例外を追加。範囲を広げすぎないことも大切です。

A1

製品と発生する有害物質

亜鉛製錬とCd、鉛ガラスとPb、りん鉱石とふっ素系物質など、原料・工程と生成物を結びつける。

A2

HF・HCl・Cl₂の個別処理

HFのアルカリ吸収、SiF₄の加水分解によるSiO₂析出、HClの吸収熱、塩素の反応吸収を比較。

A3

吸収理論の基礎

ヘンリーの法則、二重境膜説、操作線、ローディングとフラッディングの順序を押さえる。

A4

吸着装置の比較

固定層・移動層・流動層の構造、吸着剤の摩耗、吸脱着の切替、BETとLangmuirを整理。

A5

特定物質の物性

CO、Cl₂、Br₂、NH₃、SO₂、HCNの色・状態・溶解性・可燃性・毒性を比較。

A6

事故時措置の例外

立入管理、着火源管理、低所滞留、水と激しく反応する物質への散水禁止などを判断。

Bランクとして後回しにする例：個別反応の細かな条件、まれな引火点・爆発範囲の数値、少数回しか出ていない操作条件など。過去問で誤答したら追加する方式が効率的です。
