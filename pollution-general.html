04 / S RANK / ESSENTIAL

最優先は、Sランク8テーマ。

頻出性・複数年度での再登場・広い範囲を一度に理解できることを基準に設定した独自優先度。タイトルを覚えるだけでなく、解説を開いて比較しよう。

S RANK / 01重要テーマ

環境基本法の骨格と基本理念

目的・定義・基本理念・施策の基本方針を条文ごとに区別。

仕組み・覚え方を詳しく見る

「公害」と「環境の保全」は範囲が同じではない。環境基本法では、典型的な公害だけでなく、地球環境保全を含めた枠組みを定めている。

覚えるポイント：環境基本法の「目的」と「基本理念」を混同しない。

関連する出題例：R7問1R3問1
S RANK / 02重要テーマ

環境基準と排出規制の違い

環境基準は行政上の目標であり、個々の事業者に課す排出基準とは異なる。

仕組み・覚え方を詳しく見る

環境基準は大気・水質・土壌・騒音等の環境の望ましい状態を示す。排出規制は施設や排水口などの排出行為を対象にする。項目の設定状況や評価期間は種類ごとに異なる。

覚えるポイント：基準の「対象」「設定主体」「評価期間」を比較。

関連する出題例：R7問3R5問4
S RANK / 03重要テーマ

公害防止組織の制度

特定工場・事業場での管理体制を整理する。

仕組み・覚え方を詳しく見る

公害防止統括者、公害防止主任管理者、公害防止管理者などは役割や選任条件が異なる。法令が対象とする事業の範囲、施設、選任・届出の流れを学ぶ。

覚えるポイント：統括者と管理者の役割は別。細かな期限は最新条文で確認。

関連する出題例：R6問4H28問5
S RANK / 04重要テーマ

大気汚染物質と環境動向

SO₂・NO₂・SPM・PM2.5・光化学Oxの違いを押さえる。

仕組み・覚え方を詳しく見る

一次汚染物質と光化学反応による二次生成物を区別し、濃度の推移や達成状況を読み取る。測定地点の分類や年次によって値は変わるため、単一の年度値だけを暗記しない。

覚えるポイント：光化学Oxは日射下でNOxとVOC等から生成しやすい。

関連する出題例：R7問8R5問7
S RANK / 05重要テーマ

水質・地下水・土壌の現状

公共用水域の生活環境項目と健康項目を区別。

仕組み・覚え方を詳しく見る

BODとCODは同じ指標ではなく、適用される水域などが違う。公共用水域・地下水・土壌は評価する基準や測定方法が異なる。達成率や超過率は報告年度と対象をセットで覚える。

覚えるポイント：河川ではBOD、湖沼・海域ではCODが代表的。

関連する出題例：R7問10R2問4
S RANK / 06重要テーマ

地球温暖化・オゾン層保護

温室効果と成層圏オゾン破壊は別の現象。

仕組み・覚え方を詳しく見る

CO₂、CH₄、N₂O、代替フロン類などの排出・温暖化への寄与を整理。モントリオール議定書、京都議定書、パリ協定の主な対象・目的・成立の順序を区別する。

覚えるポイント：オゾン層破壊と温暖化の原因・制度を混ぜない。

関連する出題例：R3問6R2問7
S RANK / 07重要テーマ

廃棄物の分類と処理責任

産業廃棄物と一般廃棄物の区分、処理責任主体を整理。

仕組み・覚え方を詳しく見る

発生の場面だけでなく法令上の種類に沿って分類する。処理、再生利用、最終処分を区別し、数量データを読む場合は排出量と最終処分量の違いに注意する。

覚えるポイント：一般廃棄物の処理は原則として市町村が担う。

関連する出題例：H28問13R6問11
S RANK / 08重要テーマ

騒音・振動・悪臭と苦情統計

典型的な発生源と評価方法を押さえる。

仕組み・覚え方を詳しく見る

公害苦情の集計と騒音環境基準の達成状況は異なる指標。道路交通・鉄道・航空機などの騒音評価は測定位置、指標、対象が異なる。

覚えるポイント：「苦情件数」と「環境基準達成率」を混同しない。

関連する出題例：R7問12H28問12

05 / A RANK / NEXT PRIORITY

次に固める、Aランク6テーマ。

Sランクに続いて学びたい化学物質管理・ダイオキシン・環境影響評価など。上の検索欄ではS/Aをまとめて比較できます。

A RANK / 01重要テーマ

PRTR・SDSによる化学物質管理

排出・移動量の把握と危険有害性情報の伝達を区別する。

仕組み・覚え方を詳しく見る

PRTRは化学物質の排出量・移動量の把握と公表に関係し、SDSは取扱いに必要な危険性・有害性情報を伝達する。対象物質や届出条件は最新制度で確認。

覚えるポイント：PRTRとSDSは目的・情報の種類が違う。

関連する出題例：R6問14H28問14
A RANK / 02重要テーマ

ダイオキシン類・POPs

毒性等量TEQと物質群の概念を理解する。

仕組み・覚え方を詳しく見る

異性体ごとに毒性が異なるため、毒性等価係数（TEF）を用いてTEQとして評価する。排出規制・環境測定・残留性の観点を整理。

覚えるポイント：物質の総濃度とTEQは同じ値ではない。

関連する出題例：R7問14R2問14
A RANK / 03重要テーマ

公害病と原因物質

四大公害病の原因と被害の特徴を関連づける。

仕組み・覚え方を詳しく見る

水俣病・新潟水俣病・イタイイタイ病・四日市ぜんそくでは、原因物質・暴露経路・影響の現れ方がそれぞれ異なる。

覚えるポイント：水銀・カドミウム・硫黄酸化物を混同しない。

関連する出題例：R6問5H29問6
A RANK / 04重要テーマ

環境影響評価のしくみ

事業計画段階から環境影響を検討する考え方。

仕組み・覚え方を詳しく見る

環境影響評価では事業の種類・規模で対象が異なり、調査・予測・評価・環境保全措置・手続きの流れを理解する。

覚えるポイント：「すべての事業が自動的に第一種対象」ではない。

関連する出題例：R4問4H30問15
A RANK / 05重要テーマ

LCAと環境ラベル

原料調達から廃棄までの環境負荷を評価する。

仕組み・覚え方を詳しく見る

LCAの機能単位、システム境界、インベントリ分析、影響評価、解釈を整理。環境ラベルはタイプI・II・IIIの目的や検証主体を比較する。

覚えるポイント：ライフサイクルの一段階だけを見て判断しない。

関連する出題例：R7問15R5問15
A RANK / 06重要テーマ

公害統計・資料の読み方

数値そのものより、母集団・対象期間・定義を確認。

仕組み・覚え方を詳しく見る

環境白書等の表は「濃度」「排出量」「達成率」「苦情件数」の指標が混在する。地点数や業種分類も年度で変わるため、対象年度に注意して傾向を読む。

覚えるポイント：年度別の数字を現在値として使い回さない。

関連する出題例：R7問6R5問13

混同しやすい概念対象と役割確認ポイント

分析方法と出典。

対象年度：平成28年度から令和7年度。毎年15問、合計150問。各設問の中心的な主題を、9分野から1つ選んで分類し、件数と問番号別の傾向を独自に集計しました。試験問題文・選択肢・他サイトの解説画像は転載していません。

設問テーマの確認に用いた公開資料：公害防止管理者試験まとめました（やくチキ）。基準や制度の更新確認には 環境省・e-Gov法令検索 を参照してください。

分類およびS/A/Bの優先度は化学資格研究所の独自編集で、資格試験の実施機関・リンク先サイトとは提携していません。個々の設問はマップから外部ページを開いて確認できます。ページ内の過去数値は将来の出題を保証するものではありません。
