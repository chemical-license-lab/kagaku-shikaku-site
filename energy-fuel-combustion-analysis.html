高発熱量・低発熱量と水蒸気潜熱

水が液体になる際の潜熱を含めるかが差

重要ポイント・物理的な意味を確認 ＋
  • 勉強する内容：高位・低位発熱量の定義、単位、燃料別の比較を練習する
  • 物理的な意味：燃焼後の水蒸気が液化して放出する潜熱を含むのが高発熱量
  • 試験で注意：燃焼効率の分母をHHVとLHVで混在させない

  • 試験で注意：質量割合、モル割合、標準体積を混同しない

  • 試験で注意：空気基準が乾き／湿りか、標準体積かを確認
S / T06燃焼計算関連語 17/17年

空気比・過剰空気・低空気比

過剰空気を増やすと排ガスが増える関係

重要ポイント・物理的な意味を確認 ＋
  • 勉強する内容：理論空気量、実供給量、過剰空気量を一つの式で整理する
  • 物理的な意味：過剰空気が多いほど排ガス顕熱損失は増えやすい
  • 試験で注意：空気比を下げすぎると不完全燃焼・CO増加の危険
S / T07燃焼計算関連語 16/17年

水蒸気の有無と生成ガス組成の区別

  • 物理的な意味：湿り排ガス量は乾き排ガス量に水蒸気分を加える
  • 試験で注意：酸素濃度・CO₂濃度の乾き／湿り基準を統一
S / T08燃焼管理関連語 16/17年

CO₂・O₂濃度からの燃焼管理

  • 物理的な意味：空気漏入により測定O₂が高くても炉内は不完全燃焼のことがある
  • 試験で注意：簡易空気比式は燃料組成などの前提を要する
S / T09省エネ関連語 12/17年

排ガス熱損失・空気予熱

排ガス量と温度で持ち去る熱量が決まる

重要ポイント・物理的な意味を確認 ＋
  • 勉強する内容：排ガス量×平均比熱×温度差で熱損失を評価する
  • 物理的な意味：排ガス量低減と排ガス温度低下の両方が損失低減に効く
  • 試験で注意：凝縮・反応熱・熱交換損失を無条件に無視しない

  • 物理的な意味：予混合は火炎伝播速度が問題となり、拡散式は逆火リスクが相対的に低い
  • 試験で注意：燃焼速度と噴出速度による逆火・吹き消えの違い

重要公式30個を、意味から理解する。

30公式について、式の数字や係数にどんな意味があるか、変数を動かすと何が起こるかを「物理的な意味」にまとめました。各カードを開くと、式の読み方・なぜ成立するか・数値例・燃焼設備での使い方・成立条件を確認できます。

F01 / 燃焼反応

炭素の完全燃焼

C + O₂ → CO₂
物理的な意味｜まずここだけ理解

炭素原子1個が酸素分子1個と結びつき、CO₂分子1個になる「原子の帳尻」を表す。酸素は燃料から熱を取り出すための反応物であり、CO₂の質量には取り込まれた酸素の質量も含まれる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

反応係数1：1：1はモル比。同温・同圧の気体なら体積比にも読み替えられるが、固体炭素の体積には適用しない。

なぜそうなる？

炭素1 mol（12 g）に酸素1 mol（32 g）が加わるので、CO₂は44 g。燃焼後にCO₂の質量が炭素より大きくなるのは空気由来の酸素が加わるから。

数値で実感

炭素12 kgを完全燃焼させると、酸素32 kgを消費してCO₂を44 kg生じる。

現場とのつながり

石炭・重油などの元素分析から、燃料中の炭素量を出発点にCO₂発生量の理論値を推定できる。

成立条件・間違えやすい点

炭素が全てCO₂になる完全燃焼が前提。CO、すす、未燃炭素になる分は別に収支を立てる。質量比とモル比を混ぜない。

F02 / 燃焼反応

水素の完全燃焼

H₂ + ½O₂ → H₂O
物理的な意味｜まずここだけ理解

水素は炭素を含まないため、燃焼反応自体からCO₂を生成せず、水を生成する。発生する水が蒸気のまま出るか、凝縮するかが発熱量の評価に影響する。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

H₂ 1 molに対してO₂ 0.5 molが必要で、H₂O 1 molが生成。式を2倍すると2H₂＋O₂→2H₂Oとなる。

なぜそうなる？

水素原子は水の中に2個、酸素原子は1個。O₂ 1分子が水2分子に酸素原子を1個ずつ渡すため係数が½になる。

数値で実感

水素2 kgを完全燃焼させると、酸素16 kgを消費し、水18 kgを生成する（質量保存）。

現場とのつながり

水素混焼時の酸素需要、湿り排ガス量、潜熱回収の見通しを立てる起点になる。

成立条件・間違えやすい点

「燃焼時のCO₂がゼロ」と「製造・輸送まで含めた排出がゼロ」は別。高温燃焼でのNOxや火炎特性にも注意。

F03 / 燃焼反応

炭化水素の酸素需要

CₓHᵧ + (x+y/4)O₂ → xCO₂ + (y/2)H₂O
物理的な意味｜まずここだけ理解

燃料分子の「炭素x個」と「水素y個」を酸化するのに必要な酸素分子数がx＋y/4。係数は元素保存から決まり、燃料の種類が変わっても同じ手順で解ける。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

xは炭素原子数、yは水素原子数。x molのCO₂にはO原子2x個、y/2 molのH₂OにはO原子y/2個が要る。

なぜそうなる？

生成物の酸素原子の合計は2x＋y/2個。それをO₂分子2個分の原子で割るのでx＋y/4になる。

数値で実感

プロパンC₃H₈なら必要O₂は3＋8/4＝5 mol。CO₂は3 mol、水は4 mol生成する。

現場とのつながり

LPGのプロパン・ブタン比率が変わったとき、成分ごとの必要酸素量を計算して合算できる。

成立条件・間違えやすい点

炭素・水素だけからなる燃料の完全燃焼式。燃料中の酸素・硫黄・水分や不完全燃焼は別途扱う。

F04 / 燃焼反応

酸素を含む有機燃料の反応

CₓHᵧO_z + (x+y/4−z/2)O₂ → xCO₂+(y/2)H₂O
物理的な意味｜まずここだけ理解

燃料自身に結合している酸素は、生成物をつくるための酸素原子の一部を既に持ち込んでいる。そのため外から供給すべきO₂がz/2だけ少なくなる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

x,y,zは1分子中のC,H,O原子数。外部O₂の係数はx＋y/4−z/2。

なぜそうなる？

生成物に必要なO原子は2x＋y/2個。燃料がz個を供給するので、不足分（2x＋y/2−z）÷2をO₂から補う。

数値で実感

エタノールC₂H₆Oでは2＋6/4−1/2＝3 molのO₂が必要。生成物はCO₂ 2 mol＋H₂O 3 mol。

現場とのつながり

バイオ由来の酸素含有燃料や廃棄物燃焼の理論空気量計算で、炭化水素だけの式との差を説明できる。

成立条件・間違えやすい点

C,H,Oのみ・完全燃焼の仮定。窒素、硫黄、灰分などが入る場合は元素収支を追加。式が負になるような非燃料組成には機械的に適用しない。

F05 / 燃焼反応

m(O₂) = 2.667 C + 8 H + S − O
物理的な意味｜まずここだけ理解

元素分析で表した燃料1 kgを完全燃焼するための「酸素の質量」を元素ごとに積み上げる式。重い炭素・軽い水素では、同じ1 kgでも必要酸素量が大きく違う。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

C,H,S,Oは燃料1 kg当たりの各元素質量[kg/kg]。2.667＝32/12、8＝16/2、S係数1＝32/32。

なぜそうなる？

C 12 kgにはO₂ 32 kg、H 2 kgにはO₂ 16 kg、S 32 kgにはO₂ 32 kgが必要。燃料に元からあるOは外部供給分から引く。

数値で実感

燃料1 kgでC＝0.80、H＝0.10、O＝0.10、S＝0なら、O₂必要量は2.667×0.80＋8×0.10−0.10≒2.83 kg。

現場とのつながり

重油や石炭の元素分析表から空気需要を求め、燃焼用送風機の大まかな規模を見積もる際の出発点。

成立条件・間違えやすい点

燃料のOは元素としての含有酸素の質量。各値が質量%なら100で割る。酸素量[kg]を空気体積[Nm³]に直すには別途密度・基準状態が必要。

F06 / 燃焼計算

理論空気量

A₀ = V(O₂,必要) / y(O₂,空気)
物理的な意味｜まずここだけ理解

空気は酸素だけでなく、反応に直接使われない窒素なども運び込む。「必要な酸素を薄い混合気から確保するには空気を何倍送るか」を示す。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

A₀は理論空気体積、V(O₂,必要)は化学量論の酸素体積、yは酸化剤中O₂体積分率。

なぜそうなる？

酸素21%の乾き空気なら、1 Nm³中のO₂は約0.21 Nm³。必要酸素体積を0.21で割ることで全空気体積が求まる。

数値で実感

必要O₂が2.10 Nm³なら、理論空気量は2.10/0.21＝10.0 Nm³。

現場とのつながり

酸素富化でO₂濃度が増えると、同じ酸素供給に必要な酸化剤体積が減り、窒素による熱の持ち去りも減り得る。

成立条件・間違えやすい点

O₂を体積で扱うなら全体も体積、モルならモルで統一。空気のO₂分率は問題指定値を優先。理論量＝実際に供給した量ではない。

F07 / 燃焼計算

空気比

λ = A / A₀
物理的な意味｜まずここだけ理解

理論上ちょうど燃焼する量を「1」とした空気の余裕度。λが上がると通常は余剰酸素と排ガス量が増えるが、極端な低下は未燃・CO増加を招く。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Aは実供給空気量、A₀は同じ燃料量に対する理論空気量。λ＝1が量論、λ＞1が空気過剰。

なぜそうなる？

空気比は送風量の絶対値ではなく、燃料に対する供給の比。燃料流量だけが2倍ならA₀も2倍になり、空気量一定ではλは半分。

数値で実感

A₀＝10 Nm³、A＝12 Nm³ならλ＝1.20。燃料量一定でAを11 Nm³に下げるとλ＝1.10。

現場とのつながり

加熱炉では排ガスO₂やCOの測定と組み合わせて空気比を調整し、排ガス損失・NOx・未燃をバランスさせる。

成立条件・間違えやすい点

炉内の混合不均一によりλ＞1でも局所的な酸素不足が起こる。排ガス系への漏入空気がO₂測定を高く見せる場合もある。

F08 / 燃焼計算

Aₑ = (λ−1) A₀
物理的な意味｜まずここだけ理解

「多めに入れた空気」の実際の量。λは無次元の割合、AₑはNm³やkgで表す量であり、排ガス量や熱損失の増分に直接結びつく。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Aₑ＝A−A₀。λ＝A/A₀を代入するとAₑ＝（λ−1）A₀。

なぜそうなる？

過剰な空気のO₂の多くは反応せず、窒素とともに加熱されて排ガスへ出る。排出ガスの顕熱を増やす原因になる。

数値で実感

A₀＝10 Nm³、λ＝1.2ならAₑ＝2 Nm³。λを1.1にすればAₑ＝1 Nm³になり、余分な空気は半減。

現場とのつながり

空気比改善前後で増減する空気流量を求め、排ガス温度と比熱を掛けて省エネ量の概算につなぐ。

成立条件・間違えやすい点

同一燃料供給量・同じ基準状態で比較。計算上の「余剰供給空気」と炉への漏入、排ガス分析から推定した空気比は区別。

F09 / 燃焼計算

量論空燃比と当量比

φ = (F/A)/(F/A)ₛₜ = 1/λ
物理的な意味｜まずここだけ理解

当量比φは「燃料の濃さ」、空気比λは「空気の多さ」を表す互いに逆のものさし。φが大きいほど燃料リッチ、λが大きいほど燃料リーン。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

F/Aは燃料対空気の質量比またはモル比（基準統一）、添字stは量論条件。φ＝1/λ。

なぜそうなる？

燃料量が同じとき空気を増やすとF/Aは下がるのでφは下がる。一方でλは上がるため逆数関係になる。

数値で実感

λ＝1.25ならφ＝0.80（希薄）。φ＝1.10ならλ≒0.91（燃料過濃）。

現場とのつながり

予混合バーナの火炎安定性、逆火・吹き消え、排ガスNOxやCOの傾向を考える際に用いられる。

成立条件・間違えやすい点

同じ燃料・酸化剤・同じ質量/モル基準が前提。燃料過濃でも空気供給不足だけで不完全燃焼量を定量できるわけではない。

F10 / 燃焼計算

燃料炭素からのCO₂質量

m(CO₂) = (44/12) m(C)
物理的な意味｜まずここだけ理解

炭素がCO₂になると、空気から酸素の重さが加わるため生成CO₂は元の炭素より重い。係数44/12は分子量と原子量の比。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

m(C)はCO₂になった炭素の質量、m(CO₂)は生成したCO₂質量。44＝12（炭素）＋32（酸素）。

なぜそうなる？

Cの物質量n_C＝m(C)/12、生成CO₂の物質量は同じn_C。質量に戻すとn_C×44＝m(C)×44/12。

数値で実感

燃料に炭素が0.75 kg含まれ全てCO₂になるなら、CO₂＝0.75×44/12＝2.75 kg。

現場とのつながり

燃料転換で燃料の炭素質量当たり排出量を比較できる。実際の評価は有効熱量や燃料消費量も合わせる。

成立条件・間違えやすい点

COやすす、未燃炭素になった分は全量CO₂換算できない。バイオマスの会計上の扱いと煙突から出るCO₂の物理量は別。

F11 / 燃焼計算

燃焼ガスの水蒸気量

n(H₂O) = n(H原子)/2
物理的な意味｜まずここだけ理解

燃焼で燃料中の水素原子が「2個ずつ組になって」水分子になる。この生成水が、湿り排ガス量と高位・低位発熱量の差に関わる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

n(H原子)は水素原子の物質量（H₂では分子モル数の2倍）、n(H₂O)は燃焼で新たに生成した水のモル数。

なぜそうなる？

H₂O 1分子には水素原子が2個あるため、原子数を2で割って水分子数にする。炭化水素中のHも同様に数える。

数値で実感

プロパンC₃H₈を1 mol燃やすと水素原子は8 mol相当なので生成水は4 mol。

現場とのつながり

燃料別の湿り排ガス量、凝縮水の見込み、排ガス潜熱の理論的な上限の検討に使える。

成立条件・間違えやすい点

この式は「燃料の水素から生まれた水」を表す。燃料や空気が元から含む水蒸気は別に加算する。H₂のmolをH原子molと取り違えない。

F12 / 燃焼計算

乾き・湿り燃焼ガス量

Vwet = Vdry + V(H₂O)
物理的な意味｜まずここだけ理解

燃焼ガスの総量は「水蒸気も数えるか」で変わる。乾き基準の排ガスは水蒸気を除外するため、同じCO₂量でも乾き濃度の方が高くなる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Vwetは湿り排ガス体積、Vdryは水蒸気を除いた排ガス体積、V(H₂O)は水蒸気体積。全て同じ温度・圧力基準。

なぜそうなる？

ガス成分の体積は理想気体近似で足し合わせられる。H₂Oを分母に入れるとCO₂やO₂の体積濃度は希釈される。

数値で実感

乾き排ガス10 Nm³、水蒸気2 Nm³なら湿り12 Nm³。CO₂が1 Nm³なら乾き10%、湿り8.33%。

現場とのつながり

排ガス分析値を燃焼計算や排ガス量と照合するときに乾湿基準を合わせるのが必須。

成立条件・間違えやすい点

凝縮した水はガス体積に含まない。Nm³を使う場合は基準状態での気相換算という定義に注意。乾き濃度×湿り体積は誤り。

F13 / 燃焼計算

乾き排ガスの成分濃度

yᵢ,dry = Vᵢ / Vdry
物理的な意味｜まずここだけ理解

成分量を「水を除いたガス全体」で割ることで、乾き排ガス中の体積濃度が得られる。濃度が変わっても成分の絶対発生量が変わるとは限らない。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

yᵢ,dryは無次元の体積分率（×100で%）、Vᵢは乾きガス中の対象成分体積、Vdryは乾きガス全体。

なぜそうなる？

分母が小さくなるほど割合は高くなる。凝縮水の除去や漏入空気の増減が濃度表示に影響し得る。

数値で実感

CO₂ 1 Nm³／乾き10 Nm³＝10%。同じCO₂量でも漏入空気で乾きガスが12 Nm³になると8.33%。

現場とのつながり

排ガスCO₂/O₂測定値から燃焼状態を推定する際、濃度だけでなくガス流量や測定位置も確認する。

成立条件・間違えやすい点

すべて同じ温度・圧力、乾き/湿りの基準で統一。吸収法などの分析器が返す濃度の基準にも注意。

F14 / 燃焼計算

標準体積とモル

V = n R T / p
物理的な意味｜まずここだけ理解

気体の「体積」は物質の量そのものではなく、温度と圧力で伸び縮みする。燃焼計算では実流量と基準状態体積を区別することが重要。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

nはmol（またはkmol）、Rは対応した気体定数、Tは絶対温度[K]、pは絶対圧力、Vは体積。

なぜそうなる？

同じモル数なら温度を上げると体積は比例して増え、圧力を上げると体積は反比例で減る。

数値で実感

理想気体1 kmolは0℃・101.325 kPaで約22.414 Nm³。25℃・同圧なら約24.47 m³。

現場とのつながり

排ガスの流量計値をNm³/hに換算したり、モル反応量を標準体積へ変換するときに使用する。

成立条件・間違えやすい点

Nm³の基準温度は条件により異なるため、問題文の定義を確認。ゲージ圧でなく絶対圧、℃でなくKを用いる。

F15 / 燃焼計算

混合気の平均発熱量

Hmix = Σ yᵢ Hᵢ
物理的な意味｜まずここだけ理解

混合燃料1単位体積の発熱量は、各成分がその体積の何割を占めるかで決まる「加重平均」。発熱量が高い成分ほど同じ体積で大きく寄与する。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

yᵢは成分体積分率（理想気体ならモル分率）、Hᵢはその成分の単位体積当たり発熱量。

なぜそうなる？

1 Nm³の混合気はyᵢ Nm³ずつの成分に分けられると考え、各成分の発熱量yᵢHᵢを足す。

数値で実感

メタン70%（35.8 MJ/Nm³）＋水素30%（10.8 MJ/Nm³）ならLHV≒28.3 MJ/Nm³。

現場とのつながり

ガス燃料の組成が変わったときのバーナ熱入力や必要燃料流量の見通しをつけられる。

成立条件・間違えやすい点

体積分率は同一基準状態、HᵢはHHV/LHVを揃える。組成変化では密度・Wobbe指数・燃焼速度も同時に変わり得る。

F16 / 省エネ

排ガス顕熱損失

Qloss ≈ Vg cₚ,vol (Tg−Tref)
物理的な意味｜まずここだけ理解

排ガスが高温のまま煙突へ出ると、燃料から得た熱の一部を運び去る。排ガスの「量×熱をためる能力×温度差」が顕熱損失の骨格。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Vgは排ガス量[Nm³]、cₚ,volは体積基準の平均定圧熱容量[kJ/(Nm³·K)]、温度差はKまたは℃差。

なぜそうなる？

各排ガス成分を基準温度からTgまで暖めるのに要した熱量の合計。空気過剰でN₂等が増えると一般に損失が増える。

数値で実感

排ガス100 Nm³/h、cₚ,vol＝1.35 kJ/(Nm³·K)、温度差200 Kなら27,000 kJ/h＝7.50 kW。

現場とのつながり

加熱炉の排ガス温度低下や低空気比化が省エネになる理由を、熱損失として定量化できる。

成立条件・間違えやすい点

平均比熱一定の概算で、温度依存・組成変化・水蒸気凝縮の潜熱は別扱い。Nm³と実m³、質量比熱の混同に注意。

F17 / 省エネ

燃焼用空気予熱の回収熱

Qair = Va cₚ,vol (Tout−Tin)
物理的な意味｜まずここだけ理解

燃焼前の空気を予熱すると、燃料が負担していた昇温の一部を排熱が肩代わりする。熱回収器は「排ガスの熱を空気側に移し替える」装置。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Vaは予熱される空気の体積流量、cₚ,volは平均体積熱容量、Tout−Tinは空気の温度上昇。

なぜそうなる？

空気予熱器の空気側エネルギー増加は流量×比熱×温度上昇。定常・損失小なら排ガス側の冷却量に概ね等しい。

数値で実感

空気50 Nm³/h、cₚ,vol＝1.3 kJ/(Nm³·K)、50→150℃なら6,500 kJ/h（約1.81 kW）回収。

現場とのつながり

燃焼用空気予熱器の燃料削減ポテンシャル、排ガス出口温度の妥当性を概算する際に使う。

成立条件・間違えやすい点

実際の燃料節約量は熱回収量と必ずしも同一ではなく、炉効率・熱損失・負荷条件で変わる。露点腐食・汚れも考慮。

F18 / 省エネ

空気比改善による損失削減

ΔQloss = Qbefore − Qafter
物理的な意味｜まずここだけ理解

省エネ効果は改善前後の熱損失の「差」として現れる。空気比を下げた際は、主に余分な空気が排ガスとして持ち去る熱が減る。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Qbefore、Qafterは同じ時間・同じ燃料基準で評価した排ガス顕熱損失。ΔQlossが正なら損失減。

なぜそうなる？

余剰空気を減らすと排ガス量が減る。ただし炉内温度や排ガス温度が変わるので、前後でVg・cp・Tgを個別に評価する。

数値で実感

改善前の顕熱損失が30 kW、改善後が24 kWなら減少量は6 kW。

現場とのつながり

燃焼改善の投資効果を見るとき、燃料使用量・煙道O₂/CO・排ガス温度の実測と結びつけられる。

成立条件・間違えやすい点

前後で炉負荷・燃料性状が変われば単純比較不可。空気比を下げすぎるとCOやすすが増え、効率・安全が悪化し得る。

F19 / 省エネ

装置熱効率（有効熱割合）

η = Quseful / Qfuel
物理的な意味｜まずここだけ理解

燃料が持ち込む化学エネルギーのうち、加熱対象や蒸気へ届いた「役に立つ熱」の割合。単に燃料が燃え切った割合ではなく、装置全体の熱利用効率を表す。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Qusefulは対象へ伝えた有効熱量、Qfuelは燃料が投入した熱量（HHVまたはLHV基準）。両者は同じ時間・単位。

なぜそうなる？

投入熱＝有効熱＋排ガス損失＋放散損失＋未燃損失など、と収支を組めばη＝1−損失合計/Qfuel。

数値で実感

燃料入力1,000 kWに対して有効加熱850 kWなら装置熱効率85%。残り150 kWは諸損失。

現場とのつながり

ボイラ効率や加熱炉熱効率の比較、熱回収投資の評価に使える。

成立条件・間違えやすい点

この式は厳密には「装置の熱効率」。化学的な燃え切り程度を表す「燃焼効率」と混同しない。HHV/LHVで数値が変わる。

F20 / 省エネ

高位・低位発熱量の差

HHV − LHV ≈ m(water) hfg
物理的な意味｜まずここだけ理解

高位発熱量は燃焼生成水が液体まで戻るときの凝縮熱を含み、低位発熱量は水蒸気のまま出るとしてその分を含まない。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

m(water)は基準燃料量から生じる水（定義に応じ初期水分を含む）の質量、hfgは凝縮潜熱。発熱量差と同じ基準（kg燃料等）で扱う。

なぜそうなる？

水蒸気が液体になると、気化するとき必要だった潜熱を逆向きに放出する。これを回収できるかで熱量の評価が変わる。

数値で実感

CH₄ 1 molの完全燃焼ではH₂O 2 mol（36 g）。凝縮潜熱を約2.44 MJ/kgとすると差は約88 kJ/mol-CH₄。

現場とのつながり

潜熱回収ボイラの効率がLHV基準で100%超と表示される理由を理解する入口になる。

成立条件・間違えやすい点

基準温度・燃料水分・HHV/LHVの規格定義を確認。煙道で実際に凝縮しないなら潜熱は取り出せない。

F21 / 省エネ

潜熱回収量

Qlatent ≈ mcond hfg
物理的な意味｜まずここだけ理解

排ガスから水が凝縮する瞬間、蒸気の相変化に伴う潜熱が熱交換器へ渡る。温度低下による顕熱回収とは別の熱源。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

mcondは実際に凝縮した水の質量、hfgは凝縮温度における相変化潜熱。

なぜそうなる？

凝縮前後で水の状態が蒸気→液へ変わるため、同じ温度近傍でも熱を放出する。凝縮量が多いほど潜熱回収が増える。

数値で実感

水蒸気10 kg/hが凝縮し、hfg≈2,400 kJ/kgなら24,000 kJ/h≒6.67 kWの潜熱を回収。

現場とのつながり

潜熱回収型排熱回収器の熱量評価と排ガス露点・凝縮水処理の検討に使う。

成立条件・間違えやすい点

実際には顕熱も回収される。酸性成分を含む凝縮水による腐食、排ガス側圧損、伝熱面の汚れを別途考慮。

F22 / 省エネ

顕熱の温度変化

Q = m cₚ ΔT
物理的な意味｜まずここだけ理解

質量の大きい流体ほど、また温度を大きく変えるほど多くの顕熱が必要になる。比熱cₚは「1 kgを1 K温めるのに要る熱」を表す。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

mは質量[kg]、cₚは定圧比熱[kJ/(kg·K)]、ΔTは温度差[K]。流量を使う場合はQ̇＝ṁcₚΔT。

なぜそうなる？

定圧で相変化しなければエンタルピー差Δh≈cₚΔT。多量の空気を同じ温度まで加熱するには、その量に比例して熱が必要。

数値で実感

空気2 kg/s、比熱1.0 kJ/(kg·K)、昇温50 Kなら必要熱流量は100 kW。

現場とのつながり

燃焼排ガスに冷空気を混ぜる熱風製造、空気予熱、熱交換器の簡易熱収支に使う。

成立条件・間違えやすい点

気体の定圧流動の顕熱計算を想定。比熱の温度依存・相変化・混合時の基準エンタルピーに注意。

F23 / 省エネ

断熱燃焼温度の概算

Tad ≈ T₀ + Qreact / Σ(nᵢ cₚ,ᵢ)
物理的な意味｜まずここだけ理解

燃焼反応が放つ熱を外へ逃がさず、生成物だけにためたときの理論温度上昇。「燃焼熱÷生成物全体の熱容量」によって温度上昇が決まる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

T₀は反応前の基準温度、Qreactは基準燃焼熱、Σ(nᵢcₚ,ᵢ)は生成物全体のモル熱容量[kJ/K]。

なぜそうなる？

同じ発熱でも窒素・過剰空気など希釈ガスが多いほど総熱容量が増え、温度上昇は小さくなる。酸素富化は逆方向に働く。

数値で実感

燃焼熱500 kJ、生成物総熱容量0.50 kJ/Kなら温度上昇は約1,000 K（定比熱近似）。

現場とのつながり

酸素富化・排ガス再循環・水分添加が火炎温度やNOx傾向にどう作用するかを理解できる。

成立条件・間違えやすい点

高温では比熱変化やCO₂/H₂Oの解離が重要。燃料・空気の顕熱と反応熱を一貫した基準状態で収支する。

F24 / 燃焼装置

燃料投入熱量

Q̇in = V̇fuel × Hvol
物理的な意味｜まずここだけ理解

バーナに入る燃料の「毎時何Nm³」と「1Nm³当たり何MJ」を掛けると、毎時投入する化学エネルギーが出る。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

V̇fuelは標準体積流量[Nm³/h]、Hvolは発熱量[MJ/Nm³]。Q̇inは[MJ/h]。

なぜそうなる？

「単位燃料が持つエネルギー×その供給速度」という考え方。燃料流量が2倍なら同じ組成では熱入力も2倍になる。

数値で実感

燃料100 Nm³/h、低位発熱量35 MJ/Nm³なら投入熱3,500 MJ/h≒972 kW。

現場とのつながり

バーナ容量・炉の熱負荷・燃料転換時の流量変更を考える基本式。

成立条件・間違えやすい点

Nm³の基準、HHV/LHV、流量計補正を統一。燃料組成が変わると同じ体積流量でも熱入力は変わる。

F25 / 燃焼装置

燃焼室熱発生率

q̇v = Q̇in / Vchamber
物理的な意味｜まずここだけ理解

同じ投入熱でも炉内容積が小さいほど「狭い空間へ熱を詰め込む」ことになる。炉の高負荷化の程度をみる設計指標。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Q̇inは燃料の熱投入速度[kW]、Vchamberは定義された燃焼室容積[m³]、q̇vは[kW/m³]。

なぜそうなる？

容積あたり熱負荷が大きいと、小さい空間で高い熱発生を扱う必要があり、火炎形状・滞留時間・温度分布の制約が強くなる。

数値で実感

投入熱1,000 kW、燃焼室10 m³なら燃焼室熱発生率100 kW/m³。

現場とのつながり

炉の改造やバーナ大型化に際し、容量に対する燃焼負荷を比較する目安になる。

成立条件・間違えやすい点

容積の取り方とHHV/LHV基準を統一。値だけで燃焼性能が決まるわけでなく、空気混合・放射・排出物も評価が必要。

F26 / 燃焼装置

ターンダウン比

TD = 定格最大燃焼量 / 最小安定燃焼量
物理的な意味｜まずここだけ理解

バーナが「火を消さず、安定して絞れる範囲」の広さを表す。大きなターンダウン比は低負荷運転の柔軟性に役立つ。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

TDは同じバーナの最大安定燃焼量÷最小安定燃焼量。質量流量でも熱入力でも、比較条件をそろえる。

なぜそうなる？

燃料流量を下げると流速や混合状態が変わり、火炎が安定しにくくなる。構造によって最低燃焼量が違う。

数値で実感

最大1,000 kW、最小200 kWで安定燃焼できるならTD＝5：1。

現場とのつながり

負荷変動の大きいボイラ・加熱炉で、頻繁なON/OFFを避けられるか、低負荷時の効率を維持できるかに関係する。

成立条件・間違えやすい点

定格容量と最小安定容量の比。単に燃料弁を絞れる範囲ではなく、燃焼安定性・排出特性を満たす必要がある。

F27 / 燃料性状

ウォッベ指数

W = Hvol / √d
物理的な意味｜まずここだけ理解

燃料ガスの熱量だけでなく「密度でノズル流量が変わる」ことまで含めた互換性指標。圧力差が同じときの熱入力を近似的に比べられる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

Hvolは同一基準の体積発熱量、dは同条件の空気を1としたガス相対密度。

なぜそうなる？

同じ差圧・ノズルでは概ね体積流量∝1/√密度。熱入力＝流量×発熱量なのでHvol/√dが効く。

数値で実感

ガスA：H＝40、d＝0.64ならW＝50。ガスB：H＝35、d＝0.49でもW＝50（同じ発熱量単位）。

現場とのつながり

都市ガスの組成変化や他ガスへの切替時、バーナ負荷の変わりやすさを一次評価する。

成立条件・間違えやすい点

ノズル条件・供給圧力・温度・発熱量基準が同一の場合の近似。Wが等しくても燃焼速度、可燃範囲、逆火性は一致しない。

F28 / 燃焼管理

単一液滴のd²則

d²(t) = d₀² − Kt
物理的な意味｜まずここだけ理解

液滴の「直径」そのものではなく「直径の2乗」が時間に比例して減る。小さな液滴ほど急速に蒸発・燃焼し、燃え切りに必要な時間が短い。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

d₀は初期液滴径、d(t)は時刻tの径、Kは蒸発・燃焼定数[長さ²/時間]。

なぜそうなる？

液滴表面への熱移動と蒸気の拡散が釣り合う準定常モデルでは、直径二乗が一定速度で減る。燃え切り時間t_b≈d₀²/K。

数値で実感

d₀＝0.20 mm、K＝0.50 mm²/sならt_b＝0.08 s。径を半分0.10 mmにするとt_b＝0.02 s。

現場とのつながり

油バーナで微粒化を細かくするほど燃え切りが速まり、すす・未燃を減らす方向に働く理由を説明できる。

成立条件・間違えやすい点

孤立液滴・近似一定条件のモデル。実炉では噴霧分布、液滴相互作用、気流、温度でKが変化する。

F29 / 環境管理

CO₂排出原単位

I(CO₂) = m(CO₂) / Quseful
物理的な意味｜まずここだけ理解

燃料1kg当たりではなく「実際に届けた有効熱量当たり」でCO₂を比較する指標。燃料の炭素量と装置効率を一緒に評価できる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

m(CO₂)は対象期間のCO₂排出量、Qusefulは同期間の有効熱量。Iの例はkg-CO₂/MJ。

なぜそうなる？

同じ燃料でも効率が低い装置では必要燃料が増え、有効熱1MJあたりのCO₂も増える。

数値で実感

CO₂排出20 kg、有効熱100 MJならI＝0.20 kg-CO₂/MJ。

現場とのつながり

燃料転換と炉効率改善の比較では、単位燃料当たりではなく同じ製品加熱量などで揃えると公平。

成立条件・間違えやすい点

分母が供給熱か有効熱かで数値が変わる。バイオマスの排出会計・電力の間接排出・ライフサイクル評価は区別。

F30 / 環境管理

燃料の水素／炭素原子比

H/C = nH / nC
物理的な意味｜まずここだけ理解

燃料中で炭素原子1個に対して水素原子が平均いくつあるかを表す。炭素の少ない燃料ほど、同じ燃焼反応で水生成の比重が高い傾向を表せる。

式の読み方・仕組み・数値例・実務・注意点を見る
式の読み方

nHは燃料に含まれるH原子のmol、nCはC原子のmol。分子式CₓHᵧならH/C＝y/x。

なぜそうなる？

炭素は燃焼するとCO₂、水素はH₂Oになる。したがってH/Cは燃焼生成物のCO₂対水の大まかな傾向と関係する。

数値で実感

メタンCH₄はH/C＝4、エタンC₂H₆は3、プロパンC₃H₈は8/3≒2.67。

現場とのつながり

石炭・重油・天然ガスの燃料転換でCO₂排出特性を直感的に比べる補助指標になる。

成立条件・間違えやすい点

質量比ではなく原子数比。排出原単位を厳密に比べるには発熱量と設備効率が必要。純水素は炭素0でH/Cは定義できない。

記号は単元ごとに定義しています。Vは体積、mは質量、nはモル数、cは比熱、Hは発熱量、Aは空気量を表す文脈で使用。単位・熱量基準は必ず問題文に合わせてください。公式は一般的な理論の独自解説であり、過去問の解答欄の転載ではありません。
