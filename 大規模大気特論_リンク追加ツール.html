いま使っているHTMLにリンクだけを追加し、他の要素はできるだけ残します。ファイルの編集はパソコン内で完結し、外部には送信されません。

STEP 01　現在のページを選択

GitHub Desktop → Repository → Show in Explorer で、kagaku-shikaku-site を開き、pollution-air.html を選択。
このHTMLには「大気5科目一覧」へのリンクがあり、大規模大気特論への導線を追加します。

ファイルを選択してください。

STEP 02　修正版を取得

追加するリンク：「大規模大気特論｜過去10年100問の徹底分析を見る ↗」
リンク先：pollution-air-large-analysis.html

同じリンクが既にある場合は二重追加しません。ファイルの置き換え前にバックアップを取ってください。

STEP 03　GitHubに反映

ダウンロードした pollution-air.html をサイトの元の同名ファイルと置き換えます。同時に、今回の分析ページ pollution-air-large-analysis.html をサイトの直下に配置してください。その後 GitHub Desktop で Commit → Push します。
