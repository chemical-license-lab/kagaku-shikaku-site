03 / WHY THIS EQUATION?

なぜ、この式になる？

給水が蒸気へ変わるときに受け取ったエネルギーを、投入した燃料の熱で割った割合がボイラ熱効率。蒸気の量だけでなく、給水と蒸気のエンタルピー差が重要。

  1. 01

    燃料から、単位時間当たり Q̇燃料 の熱エネルギーを供給する。

  2. 02

    給水1 kgを蒸気にするため、エンタルピーは (h蒸気 − h給水) kJ/kg だけ増える。

  3. 03

    1秒に ṁ蒸気 kgの蒸気を作ると、有効熱流量は ṁ蒸気 × (h蒸気 − h給水)。

  4. 04

    有効熱を燃料熱入力で割れば、ボイラ熱効率 η が得られる。

ANALOGY / たとえで理解

身近な現象に置き換える。

やかんにガスの熱を入れても、全てがお湯には届かない。炎や排気に逃げた分を差し引き、水が受け取った割合を考える。

CONDITIONS / 成立条件

定常運転・同じ発熱量基準で算定。ブロー・給水流量・補助燃料等がある場合は詳細収支で扱う。

FIELD / 実際の設備

どこで使う？

蒸気負荷、給水予熱、煙道排熱回収、過剰空気低減を検討する際の基本。

SAVING POINT / 省エネの着眼点

何を改善する？

排ガス・放射・ブローなどの損失を別々に測ると、改善すべき場所が見えてくる。

CAUTION / 注意点

条件を忘れない。

効率は高位発熱量/低位発熱量で数値が変わる。燃焼効率とボイラ熱効率を混同しない。

数字で考えてみよう。

計算例

  2. 燃料の熱入力 6,000 kW なら η = 5,000/6,000 = 83.3%。
計算結果ボイラ熱効率 83.3%

03 / WHY THIS EQUATION?

なぜ、この式になる？

排ガスが冷えると、その温度差に対応する顕熱が減る。その熱を給水や燃焼空気に渡せば、新たな燃料による加熱量を減らせる。

  1. 01

    排ガスは「温度が高い流体」なので比熱に応じた顕熱を持つ。

  2. 02

    排ガス1 kgが ΔT K 冷えると放出する熱は約 cₚΔT。

  3. 03

    1秒あたり ṁ排 kgの排ガスなら、回収できる顕熱の目安は ṁ排 cₚΔT。

  4. 04

    回収側へ熱が実際に渡る温度差、伝熱面積、腐食・結露の制約を確認する。

ANALOGY / たとえで理解

身近な現象に置き換える。

熱いお風呂の残り湯で、冷水を直接温められるなら、給湯器の燃料を減らせるイメージ。

CONDITIONS / 成立条件

排ガス比熱一定・潜熱回収なし・回収器の外部損失を無視した概算。酸露点・凝縮・汚れ・煙突ドラフトに注意。

FIELD / 実際の設備

どこで使う？

ボイラ給水を温めるエコノマイザ、燃焼空気を温める空気予熱器。

SAVING POINT / 省エネの着眼点

何を改善する？

高温排ガスの使用可能な温度帯と熱需要（給水・空気）を結び付けて評価する。

CAUTION / 注意点

条件を忘れない。

排ガスを極端に冷やすと酸性凝縮液や低温腐食が問題になる。温度差がない所では熱は移せない。

数字で考えてみよう。

計算例
  1. 排ガス 2 kg/s、比熱1.1 kJ/(kg·K)、温度差150 K。
  2. 回収可能な顕熱は 2×1.1×150 = 330 kW（理論目安）。
計算結果排ガス顕熱 330 kW

蒸気配管と保温

表面から逃げる熱を止める

Q̇損失 ≈ U A (T配管 − T周囲)
01 / FIRST, THE PHENOMENON

蒸気が高温なほど周囲との温度差が大きく、配管の外へ熱が逃げやすい。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

保温材は熱が外へ移る通り道に大きな熱抵抗を加える。断熱性が良いほど全体の熱の通りやすさUが下がり、損失熱が減る。

  1. 01

    蒸気の熱は管壁、保温材、外気側の境膜を順に通り抜ける。

  2. 02

    各段階には熱抵抗があり、直列の抵抗を足して全体の伝わりやすさUを表す。

  3. 03

    同じ温度差・面積なら熱損失は U A ΔT で近似できる。

  4. 04

    保温材でUを減らせば、周囲へ失う熱も減る。

ANALOGY / たとえで理解

身近な現象に置き換える。

冬の上着は体内の熱を作り出さず、外へ逃げる速さを小さくしている。保温材の役割も同じ。

CONDITIONS / 成立条件

Uは使用する面積基準・保温厚さ・表面放射・外気条件に依存。温度が一定、定常の概算。

FIELD / 実際の設備

どこで使う？

蒸気配管、バルブ、フランジ、ドレンポットなど保温の抜けやすい場所の損失低減。

SAVING POINT / 省エネの着眼点

何を改善する？

未保温箇所の特定、劣化した保温材の更新、保温下腐食（CUI）対策も重要。

CAUTION / 注意点

条件を忘れない。

裸管と保温管を比較するときは外表面積も変化する。正確には円筒熱抵抗・対流・放射を考慮。

04 / WORKED EXAMPLE

数字で考えてみよう。

計算例
  1. 配管面積20 m²、温度差120 K、保温後U=1.0 W/(m²·K)。
  2. 熱損失 = 1.0×20×120=2,400 W=2.4 kW。
計算結果保温後の熱損失 2.4 kW

蒸気トラップ・ドレン回収

蒸気と液体を分けて、熱を取り戻す

x = (h入口 − hƒ,低圧) / hƒg,低圧
01 / FIRST, THE PHENOMENON

蒸気配管で生じたドレンを適切に排出し、その温水の熱を捨てずに回収する。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

高圧側の熱いドレンが減圧されると、低圧の飽和水より多く持つエンタルピーの一部が蒸発潜熱に変わり、フラッシュ蒸気が発生する。

  1. 01

    蒸気が冷えて凝縮すると、高温のドレン（水）が残る。

  2. 02

    ドレンを圧力の低い容器へ絞ると、ほぼ等エンタルピーのまま低圧側へ移る。

  3. 03

    低圧での混合物のエンタルピーは h = hƒ + x hƒg。

  4. 04

    入口hと一致させて整理すると x=(h入口−hƒ)/hƒg。

ANALOGY / たとえで理解

身近な現象に置き換える。

熱いお湯の入った容器の圧力を急に下げると、一部の水が蒸気になる。この蒸気も回収できる熱エネルギーを持つ。

CONDITIONS / 成立条件

断熱・仕事なし・速度変化無視の絞りで、低圧側が湿り飽和状態（0≤x≤1）の場合。生蒸気漏れと区別。

FIELD / 実際の設備

どこで使う？

蒸気トラップの適切な選定、ドレン再利用、フラッシュタンクでの低圧蒸気利用。

SAVING POINT / 省エネの着眼点

何を改善する？

ドレンの温度・回収量を把握し、戻せる熱の温度レベルと受け入れ先を確認する。

CAUTION / 注意点

条件を忘れない。

蒸気トラップの生蒸気漏えいは省エネではない。ウォーターハンマー、背圧、凍結にも注意。

04 / WORKED EXAMPLE

数字で考えてみよう。

計算例
  1. 入口h=700、低圧飽和水hƒ=420、潜熱hƒg=2250 kJ/kg。
  2. x=(700−420)/2250=0.1244 → 約12.4%がフラッシュ蒸気。
計算結果フラッシュ蒸気率 約12.4%

伝熱・熱交換 / 05PRINCIPLE → SAVING → PRACTICE

熱交換器の温度差と伝熱量

熱い流体から冷たい流体へ

Q̇ = U A ΔTₗₘ
01 / FIRST, THE PHENOMENON

熱交換器の中で、温度が高い流体から低い流体に熱が渡る。流路に沿って温度差は変化する。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

熱の動きやすさを決めるUと面積Aに、温度差の代表値ΔTₗₘを掛けると、熱交換器で受け渡す熱流量が求まる。

  1. 01

    局所的な熱流束は、その場所の温度差 ΔT に比例する。

  2. 02

    熱い流体は冷え、冷たい流体は温まるので、ΔTは熱交換器の長さに沿って一定ではない。

  3. 03

    流量・熱容量流量・Uが一定などの条件で伝熱の関係を積分すると、対数平均温度差ΔTₗₘが現れる。

  4. 04

    全体の熱量は Q̇ = UAΔTₗₘ。両流体の熱収支でも同じQ̇になる必要がある。

ANALOGY / たとえで理解

身近な現象に置き換える。

隣り合った部屋を隔てる壁越しの熱移動を想像。片側が徐々に冷え、反対側が温まるため、場所によって温度差が変わる。

CONDITIONS / 成立条件

定常、U一定、温度差の端点が正しく対応。多管程・多胴程は補正係数Fを要する場合あり。

FIELD / 実際の設備

どこで使う？

予熱器、冷却器、凝縮器、ボイラ給水加熱器、排熱回収器。

SAVING POINT / 省エネの着眼点

何を改善する？

流路形式（向流/並流）、必要な熱回収温度、伝熱面積、圧力損失をまとめて評価。

CAUTION / 注意点

条件を忘れない。

入口温度差だけでは評価できない。温度クロスやピンチ温度差がある場合は方式選定が必要。

伝熱・熱交換 / 06PRINCIPLE → SAVING → PRACTICE

熱交換器の汚れと能力低下

壁に付着した汚れも「熱抵抗」

1/U汚れ = 1/U清浄 + Rƒ
01 / FIRST, THE PHENOMENON

汚れた伝熱面は熱を通しにくくなり、同じ温度差でも冷却・加熱能力が下がる。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

伝熱管の壁・流体側境膜・付着した汚れが熱抵抗として直列に並ぶ。汚れ抵抗Rƒが増えると、逆数1/Uが増えるためUが小さくなる。

  1. 01

    熱の移動には、高温側境膜・管壁・低温側境膜の抵抗がある。

  2. 02

    スケールや付着物が増えると、熱の通路にもう一つ抵抗Rƒが追加される。

  3. 03

    同じ面積基準なら抵抗は加算でき、1/U汚れ=1/U清浄+Rƒ。

  4. 04

    Uが下がれば、Aや温度差が同じ場合に伝熱量が減る。

ANALOGY / たとえで理解

身近な現象に置き換える。

窓に断熱フィルムを追加すると熱が通りにくくなる。熱交換器のスケールも、意図しない断熱層として働く。

CONDITIONS / 成立条件

Uの逆数やRƒは同じ面積基準。実際の円管は内外面積が異なり、流量や温度差も連動する。

FIELD / 実際の設備

どこで使う？

定期洗浄、ファウリング監視、冷却塔水質管理、伝熱能力の寿命評価。

SAVING POINT / 省エネの着眼点

何を改善する？

清浄・汚れのUと温度差の推移を、運転負荷を補正して比較する。

CAUTION / 注意点

蒸留・蒸発の熱利用

塔の上と下で熱をどう使う？

Q̇潜熱 ≈ ṁ蒸発 × Δh蒸発
01 / FIRST, THE PHENOMENON

蒸留は混合物を沸かして分離し、蒸気を凝縮する。再沸器と凝縮器で大きな熱を動かしている。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

液を蒸気に変えるには蒸発潜熱が必要。蒸気を凝縮すると同程度の潜熱を外部へ放出するため、熱の回収可能性を考えられる。

  1. 01

    蒸発には分子間の結び付きをほどくための潜熱が必要。

  2. 02

    蒸発する量ṁ［kg/s］と単位質量あたり潜熱Δh［kJ/kg］を掛ける。

  3. 03

    蒸発に要る熱流量の目安はṁ×Δh。凝縮器では熱を捨てる側になる。

  4. 04

    温度レベルが合えば蒸気再圧縮や熱統合で、加熱と冷却の両方を抑えられる。

ANALOGY / たとえで理解

身近な現象に置き換える。

お湯を沸かすために熱を入れ、蒸気を冷まして水に戻すと熱が出る。蒸留塔でもこの両側の熱利用を考える。

CONDITIONS / 成立条件

単純な潜熱のみの近似。実際の蒸留塔は還流比、組成、顕熱、段効率、塔圧や熱損失が関わる。

FIELD / 実際の設備

どこで使う？

蒸留塔のリボイラ・コンデンサ、蒸発濃縮、MVR、ヒートポンプ蒸留。

SAVING POINT / 省エネの着眼点

何を改善する？

蒸留条件の適正化、塔圧変更、還流量削減、熱統合の温度レベルの検討。

CAUTION / 注意点

条件を忘れない。

凝縮熱の全量がそのまま再沸器に使えるわけではない。温度差（熱の質）が足りない場合は昇温が必要。

コージェネレーション

発電後の排熱も「使う」

η総合 = (P電 + Q̇有効熱) / Q̇燃料
01 / FIRST, THE PHENOMENON

燃料の熱を電気だけでなく蒸気・温水として回収できると、総合利用効率は高まる。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

単独発電では排熱になる部分を工場の熱需要へ回すことで、同じ燃料から得られる有効エネルギーの割合が上がる。

  1. 01

    燃料エネルギーをエンジンやガスタービンへ供給する。

  2. 02

    一部を電力P電として取り出す。

  3. 03

    排熱回収ボイラなどで余熱を有効蒸気・温水Q̇有効熱として利用する。

  4. 04

    電力と利用可能な有効熱の合計を燃料熱入力で割ったものが総合利用率。

ANALOGY / たとえで理解

身近な現象に置き換える。

発電機の排気熱をそのまま捨てる代わりに、お風呂を沸かす熱へ再利用するイメージ。

CONDITIONS / 成立条件

投入燃料と出力は同じ熱量基準で比較。電力・熱の価値（エクセルギー）は同等ではない。

FIELD / 実際の設備

どこで使う？

自家発電、排熱回収ボイラ、工場の蒸気と電力の同時供給。

SAVING POINT / 省エネの着眼点

何を改善する？

熱電需要の時間変動・買電単価・排出係数・部分負荷運転の組合せで評価する。

CAUTION / 注意点

条件を忘れない。

熱需要がないと回収熱は有効利用できない。総合利用率が高いだけでCO₂や費用が必ず減るとは限らない。

計測・制御と省エネ

測る → 比べる → 調整する

PV = L + (I − 4) / 16 × (U − L)
01 / FIRST, THE PHENOMENON

設備を改善するには温度・流量・圧力・エネルギー量を測り、目標からの差を減らす制御が必要。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

4〜20 mAの信号を測定範囲へ変換する基本式。4mAが下限、20mAが上限なので、16mA分の幅で割る。

  1. 01

    伝送器が測定した温度・圧力などの量を、4〜20mAへ線形に割り付ける。

  2. 02

    信号の下限4mAを引くと、ゼロ点からの相対量が得られる。

  3. 03

    全幅16mAで割ると、0〜1の割合に直せる。

  4. 04

    この割合を測定スパン(U−L)に掛けて下限Lを足せば物理量PVに戻る。

ANALOGY / たとえで理解

身近な現象に置き換える。

0〜100点のテストを4〜20の目盛りで表示していると考える。目盛り12は全体の50%地点。

CONDITIONS / 成立条件

伝送器が線形校正されている範囲。実際の制御はノイズ・計測誤差・時定数・センサ位置等にも影響される。

FIELD / 実際の設備

どこで使う？

蒸気流量制御、酸素濃度計、熱交換器出口温度制御、エネルギー原単位監視。

SAVING POINT / 省エネの着眼点

何を改善する？

測定から改善までのPDCA、運転データの傾向監視、定期校正。

CAUTION / 注意点

条件を忘れない。

制御の設定値を下げるだけで品質・安全が保てるとは限らない。過剰制御やセンサ不良も確認。

設備の改善を数字で判断する

回収年数 = 投資額 ÷ 年間削減額
01 / FIRST, THE PHENOMENON

省エネ改善は「何kWh減るか」だけでなく、生産量・費用・運転時間もそろえて評価する。

02 / EQUIPMENT DIAGRAM

熱とエネルギーの流れを見る。

オリジナル模式図

図は原理説明用の模式図。実設備の寸法や全ての配管構成を表したものではありません。

03 / WHY THIS EQUATION?

なぜ、この式になる？

設備投資の初期費用を、年間の削減費用で割った簡易評価が単純回収年数。エネルギー原単位と併せて見れば生産量の違いを考慮できる。

  1. 01

    まず改善で減る電力・燃料の量を、運転時間を含めて計算する。

  2. 02

    削減エネルギーに単価を掛け、年間の削減額に直す。

  3. 03

    投資額を年間削減額で割ると、単純回収年数が分かる。

  4. 04

    生産量・品質・設備寿命・保全費・割引率なども確認し、実施を判断する。

ANALOGY / たとえで理解

身近な現象に置き換える。

高価だけど電気代が安くなる冷蔵庫を買うとき、差額を毎年の電気代節約で何年かけて取り戻すか考えるのと同じ。

CONDITIONS / 成立条件

年間削減額が一定とする単純回収法。キャッシュフロー割引・燃料価格変動・保守費等は含めない。

FIELD / 実際の設備

どこで使う？

インバータ更新、排熱回収、保温改修、設備統廃合、運転最適化の投資評価。

SAVING POINT / 省エネの着眼点

何を改善する？

回収年数だけでなく、CO₂削減、停止リスク、管理負荷、投資採算性を総合評価。

CAUTION / 注意点

条件を忘れない。

「消費エネルギー総量が減少＝原単位改善」とは限らない。生産量・基準条件をそろえる。
