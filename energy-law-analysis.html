S01法令本文登場 17/17年

事業者区分・指定工場・選任

制度の骨格を説明できることが先決。

重要事項・つまずきポイント
  • 「事業者の指定」と「個々の工場等の指定」を分けて考える。
  • エネルギー管理統括者・企画推進者・管理者・管理員の役割を整理する。
  • 原油換算値の計算では使用場所・対象エネルギーと単位を最初に確認する。

注意：指定基準・人数・期限は受験年度の施行法令で確認。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S02法令本文登場 17/17年

定期報告・中長期計画・原単位

書類の主体と管理指標の意味を整理。

重要事項・つまずきポイント
  • エネルギー消費原単位はエネルギー使用量を生産量等の活動量で割る指標。
  • 定期報告と中長期計画の目的・対象者・提出先を区別する。
  • 改善率と原単位の増減、単位の不一致による失点に注意。

注意：古い問題の条番号・届出様式を現行のものと混同しない。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S03法令本文登場 10/17年

判断基準・管理標準・設備運用

管理体制、測定・記録、保守を結びつける。

重要事項・つまずきポイント
  • 管理標準の設定・運転管理・測定記録・保守点検の流れを説明する。
  • 燃焼設備、加熱設備、空調設備、電動機・照明の管理項目を横断的に整理。
  • 省エネ提案の一般論と、判断基準の法令上の要求を区別する。

注意：機器の最適運転は「設定」だけでなく測定と記録までが管理。

関連テーマの登場年度例：H29 / R1 / R3 / R7 / R8

S04法令本文登場 4/17年

非化石転換・電気需要最適化

令和5年度以降の改正を最優先で押さえる。

重要事項・つまずきポイント
  • 省エネルギーの合理化と、非化石エネルギーへの転換は目的と報告事項が違う。
  • 電気需要の最適化は単なる総消費量削減と同じではない。
  • 非化石燃料・非化石熱・非化石電気を対象とした説明を整理する。

注意：改正前の条文に基づく過去問をそのまま丸暗記しない。

関連テーマの登場年度例：R5 / R6 / R7 / R8

S05概論本文登場 8/17年

SI単位・熱量・原油換算

最初の計算で落とさない単位感覚。

重要事項・つまずきポイント
  • 1 kWh＝3.6 MJ。kW×hをkWhに直してからエネルギー換算。
  • J=N·m、W=J/s、Pa=N/m²と基本単位を展開できる。
  • 原油換算は、その年度・問題に与えられた換算係数を用いる。

注意：絶対温度Kと℃、MWとMWhを混同しない。

関連テーマの登場年度例：R1 / R4 / R6 / R7 / R8

S06熱本文登場 17/17年

燃焼・空気比・排ガス計算

物質収支で酸素・理論空気量を算出。

重要事項・つまずきポイント
  • C + O₂ → CO₂、2H₂ + O₂ → 2H₂Oなど、基礎反応から理論酸素量を求める。
  • 空気比 λ＝実供給空気量／理論空気量。
  • 排ガス濃度で湿り・乾き基準の違いに注意する。

注意：酸素・窒素の分率を体積基準と質量基準で取り違えない。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S07熱本文登場 17/17年

伝熱・熱抵抗・熱放射

熱抵抗合成と絶対温度の4乗。

重要事項・つまずきポイント
  • 平板の定常熱伝導 Q̇＝λAΔT/L。
  • 複合壁の熱抵抗 R＝Σ(L/λA)＋境膜抵抗を使う。
  • 放射熱は絶対温度の4乗に比例。温度比は必ずKで。

注意：総括伝熱係数の基準面積と単位を確認。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S08熱本文登場 16/17年

蒸気・ボイラー・熱収支

燃料から蒸気への熱の流れを説明。

重要事項・つまずきポイント
  • ボイラー効率＝有効に得られた熱量／投入熱量。
  • 湿り蒸気の比エンタルピー h＝h_f＋x(h_g−h_f)。
  • ドレン回収、保温、排ガス熱回収が省エネに寄与する。

注意：燃料の高位・低位発熱量を混同しない。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S09電気本文登場 17/17年

三相交流・有効電力・力率

√3とcosφを使い分ける。

重要事項・つまずきポイント
  • 三相有効電力 P＝√3VIcosφ（線間電圧・線電流）。
  • 力率改善では無効電力 Q=P(tanφ₁−tanφ₂) を利用する。
  • 変圧器は無負荷損と負荷損を分けて考える。

注意：有効kW、無効kvar、皮相kVAを区別。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

S10電気本文登場 10/17年

30分デマンド・電力管理

残り時間から許容平均電力を計算。

重要事項・つまずきポイント
  • 最大需要電力は一般に30分単位で管理する。
  • 目標電力量＝目標需要電力×0.5h。
  • 残り時間に使用できる平均電力＝（目標電力量−使用済み電力量）／残り時間。

注意：kW（電力）とkWh（電力量）を取り違えない。

関連テーマの登場年度例：R2 / R3 / R4 / R5 / R8

S11電気本文登場 12/17年

ポンプ・送風機・インバータ

流量・圧力損失・軸動力をつなぐ。

重要事項・つまずきポイント
  • 流体動力＝体積流量×圧力差（SI単位）。
  • ポンプ軸動力は効率で割る。
  • 相似条件では回転数比に応じQ∝n、H∝n²、P∝n³を利用する。

注意：相似則は羽根車径・流体特性が同じ条件で。

関連テーマの登場年度例：R3 / R4 / R5 / R6 / R8

S12熱本文登場 17/17年

空調・冷凍・COP・ヒートポンプ

熱量と消費電力の関係を把握。

重要事項・つまずきポイント
  • 冷凍機COP＝冷凍能力／入力。ヒートポンプ暖房COP＝暖房能力／入力。
  • 外気負荷・顕熱負荷・潜熱負荷を分ける。
  • 運転時間、設定温度、部分負荷効率を考慮する。

注意：エネルギー効率と設備容量を同一視しない。

関連テーマの登場年度例：R4 / R5 / R6 / R7 / R8

A04熱本文登場 9/17年

発電効率・コージェネ

発電と熱回収を分けて評価。

重要事項・つまずきポイント
  • 発電効率＝電気出力／燃料投入熱量。

08 / FORMULAS 18

計算問題は、この18公式から。

設問の数字が変わっても解法を再利用できる。先に物質・熱・電力の収支を描き、次に単位を合わせて代入する。

01 / エネルギー換算E［MJ］= 3.6×電力量［kWh］

単位の桁と小数点を確認

02 / 負荷率負荷率 = 平均負荷 ÷ 最大負荷

平均値の対象期間が一致しているか

03 / 熱量Q = mcΔT

比熱と質量と温度差

04 / 潜熱Q = mL

相変化では温度一定の場合も

05 / 燃焼空気比λ = 実空気量 / 理論空気量

乾き排ガス・湿り排ガス

06 / 蒸気の乾き度h = h_f + x(h_g−h_f)

xは蒸気質量割合

07 / 定常伝導Q̇ = λAΔT/L

厚さL・面積A・伝導率λ

08 / 熱抵抗Q̇ = ΔT / ΣR

複合壁の抵抗を足す

09 / 放射Q̇ = εσA(T₁⁴−T₂⁴)

絶対温度Kのみ

10 / 発電効率η = 電力出力 / 燃料投入熱量

効率の分母を要確認

11 / 冷凍機COPCOP = 冷凍能力 / 入力

暖房COPと異なる

12 / 三相有効電力P = √3 VI cosφ

線間電圧・線電流で使用

13 / 力率改善容量Q_c = P(tanφ₁−tanφ₂)

kvarをkWと混同しない

14 / ポンプ軸動力P = QΔp/η

Q：m³/s, Δp：Pa

15 / 送風機相似則Q∝n, H∝n², P∝n³

同一機械・相似運転

16 / 需要制限P残 = (P目標×0.5h−E済)/t残

電力量の単位と残り時間

17 / カルノー効率η=1−T_c/T_h

18 / 電解析出量m = MIt/(zF)

価数zと電流効率
