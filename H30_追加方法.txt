化学資格研究所｜平成30年度（H30）追加パック v0.8
================================================

このZIPは「追加・更新するファイルだけ」を収録しています。

【Windowsでの導入】
1. ZIPを右クリック →「すべて展開」して、中にあるファイルとフォルダを確認。
2. GitHub Desktop → kagaku-shikaku-site → Show in Explorer で開く。
3. ZIPの中身を kagaku-shikaku-site フォルダの「直下」にコピー。
   ※ assets フォルダは中身が追加されるように統合してOK。
   ※ content フォルダも同様。
   ※ 既存の同名 HTML / JSON があれば「ファイルを置き換える」を選ぶ。
   ※ このパックに .git フォルダは入っていません。
4. GitHub Desktop の Changes で差分を確認。
5. Summary に「Add H30 illustrated past papers」と入力 → Commit to main。
6. 画面上部の「Push origin」をクリック。
7. GitHub Pagesの更新を少し待ち、サイト上で平成30年度のリンクを確認。
